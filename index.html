🎵 Spotireachy

Voice-Controlled Music Player for Reachy Mini

Faites danser votre Reachy Mini au rythme de la musique ! 🕺

Spotireachy transforme votre Reachy Mini en DJ intelligent. Parlez-lui, et il trouvera et jouera vos chansons préférées tout en dansant synchronisé au BPM !

✨ Fonctionnalités

🎤

Reconnaissance Vocale

Commande vocale locale avec Whisper - fonctionne offline

🔍

Recherche Sémantique

Trouve la bonne chanson même avec des commandes approximatives

🗣️

Confirmation TTS

Reachy confirme vocalement avant de jouer

💃

Danse Synchronisée

Mouvements au rythme du BPM de la chanson

📊

Extraction BPM

Analyse automatique du tempo avec librosa

🎵

Multi-formats

Support MP3, WAV, FLAC, M4A

🚀 Installation

Via Dashboard Reachy Mini (Recommandé)

  1. Ouvrez le dashboard Reachy Mini
  2. Cliquez sur "App Store"
  3. Cherchez "Spotireachy"
  4. Cliquez sur "Installer"

Via uv (rapide ⚡)

# Cloner le projet
git clone https://huggingface.co/spaces/YOUR_USERNAME/spotireachy
cd spotireachy

# Installer avec uv
uv sync

# Indexer votre musique
cp ~/Music/*.mp3 music/
uv run spotireachy-index

# Lancer
uv run spotireachy

Via Make

make setup  # Installation complète
make index  # Indexer la bibliothèque
make run    # Lancer l'application
